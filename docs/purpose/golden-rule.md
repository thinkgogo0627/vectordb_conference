# Golden Rule

- GR-01 모든 실험은 같은 리플레이 입력과 같은 평가 하네스로 잰다 — 이유: 실험 0·1·2 결과를 한 줄로 비교하기 위해 / 적용 범위: P1~P3 전 실험 / 출처: D-06
- GR-02 정답 기준은 항상 Postgres(리더)다. 벡터 인덱스의 상태는 Postgres 최신 리비전과 비교해 판정한다 — 이유: 간극의 정의가 원본 대비 차이이므로 / 적용 범위: 모든 채점 / 출처: D-06
- GR-03 결과를 해석할 때 주입한 설정값(embed_ms, 배속, 반영 주기 등)에서 나온 효과와 시스템 자체에서 나온 효과를 구분해 기록한다 — 이유: 사전 계산 임베딩과 로컬 환경 때문에 결과가 설정값에 좌우될 수 있다 / 적용 범위: 모든 결과 해석·발표 / 출처: D-03
